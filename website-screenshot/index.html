Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~website-screenshot/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "urls": [
    "https://example.com",
    "https://www.wikipedia.org"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/website-screenshot").call(run_input={'urls': ['https://example.com', 'https://www.wikipedia.org']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
