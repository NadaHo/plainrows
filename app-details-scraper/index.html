Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~app-details-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "apps": [
    "https://play.google.com/store/apps/details?id=com.spotify.music",
    "https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580"
  ],
  "country": "us",
  "language": "en"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/app-details-scraper").call(run_input={'apps': ['https://play.google.com/store/apps/details?id=com.spotify.music',
          'https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580'],
 'country': 'us',
 'language': 'en'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
