Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~domain-seo-overview/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "apify.com",
    "moz.com"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/domain-seo-overview").call(run_input={'domains': ['apify.com', 'moz.com'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
