PPC competitor research, Google Ads competitor keywords and MCP tool: the paid keywords any website buys, with ad position, landing page, ad text, CPC, volume and monthly ad spend. Bulk domains, 94 countries, organic too. Pay per domain and keyword found, plus a $0.012 start fee per run.

Try it on Apify  

Typical uses

  • See which keywords a competitor pays for on Google Ads, what its ads say and which landing pages they send to.
  • Estimate a competitor's Google Ads budget (`paidTrafficCostUsd`) and paid traffic, for one site or hundreds in one run.
  • Find keywords worth bidding on: the terms your competitors advertise on, with volume and CPC, as a spreadsheet with one row per keyword.
  • Qualify leads by their ad spend: agencies can spot businesses that already advertise on Google.
  • Track competitors' ads over time by scheduling runs; feed n8n / Make workflows, dashboards or AI agents with clean JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~ppc-competitor-keywords/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "semrush.com"
  ],
  "country": "US",
  "keywordType": "paid"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/ppc-competitor-keywords").call(run_input={'domains': ['semrush.com'], 'country': 'US', 'keywordType': 'paid'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
