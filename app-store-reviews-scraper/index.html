App Store Reviews Scraper: iOS Ratings, Titles & Text

Scrape Apple App Store reviews of any iPhone or iPad app: stars, review title, text, date and app version, in 20 countries (up to 500 per app and country). Paste an App Store ID or link. No reviewer names. Only-new-reviews mode for daily alerts. Pay per review plus small fetch and start fees.

Try it on Apify  

Typical uses

  • Product feedback and bug triage: read what iOS users say about the latest version, newest first, with the app version each review was written for.
  • Competitor research: compare your app's ratings and complaints with competitors' on the App Store, country by country.
  • Review monitoring: turn on Only new reviews, schedule a daily run and alert your team in Slack or a spreadsheet: you never get (or pay for) the same review twice.
  • Sentiment analysis and AI summaries: feed clean review titles and text to an LLM, a BI tool or an AI agent (MCP).
  • App Store Optimization (ASO): find the words users use in titles and reviews, and what drives 1-star ratings.

Ready-to-run examples

  • App Store reviews in Germany (most helpful): Export the most helpful German App Store reviews of an iPhone app (Instagram here), with review title, text, stars, date and app version. Change the app ID or the country.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~app-store-reviews-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "apps": [
    "https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580",
    "570060128"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/app-store-reviews-scraper").call(run_input={'apps': ['https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580',
          '570060128'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
