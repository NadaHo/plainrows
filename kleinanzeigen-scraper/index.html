Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~kleinanzeigen-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "https://www.kleinanzeigen.de/s-berlin/fahrrad/k0l3331",
    "iphone 15"
  ],
  "maxResultsPerSearch": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/kleinanzeigen-scraper").call(run_input={'searches': ['https://www.kleinanzeigen.de/s-berlin/fahrrad/k0l3331',
              'iphone 15'],
 'maxResultsPerSearch': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
