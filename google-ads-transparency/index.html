Google Ads Scraper & API: Google Ads Transparency Center

Google Ads scraper and MCP tool: every Google ad a competitor runs (Transparency Center) from a domain, brand or advertiser ID: creative ID, format, preview image, first and last shown, days running. Filters: country, platform, format, dates. New-ads alerts. Pay per ad plus a fee per advertiser.

Try it on Apify  

Typical uses

  • Competitor ad monitoring: which ads a competitor runs right now, since when, and in which format. Turn on Only new ads and schedule the run to get only newly launched ads each day or week.
  • Creative research: collect text, image and video ads of a brand or a whole market, with preview images, to see what works (long-running ads are usually the winners: sort by `daysRunning`).
  • Agency prospecting (ad check): check which prospects advertise on Google, and how much (`totalAdsApprox`). Set `maxAdsPerTarget` to 1 for one row per advertiser.
  • Brand protection: find other advertisers sending ads to your domain (resellers, affiliates, agencies).
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Ready-to-run examples

  • See which Google ads a competitor is running: List the ads a company runs on Google (Search, YouTube, Display) from the Ads Transparency Center: format, preview, first and last shown, days running.
  • Find a brand's video ads on YouTube: Get the video ads a brand runs, with preview links and how long each ad has been running.
  • Get alerted when a competitor launches new Google ads: Schedule this task daily or weekly: the first run lists current ads, each later run returns only ads launched since, so you pay only for new ads. Send them to Slack, e-mail or a sheet.
  • Check which companies advertise on Google: Ad check for prospect lists: one row per company with its approximate number of Google ads (totalAdsApprox), or a free 'no-ads' row. Useful for agencies qualifying leads.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-ads-transparency/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "targets": [
    "nike.com"
  ],
  "country": "ANY"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-ads-transparency").call(run_input={'targets': ['nike.com'], 'country': 'ANY'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
