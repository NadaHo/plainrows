Amazon keyword research tool, Helium 10 alternative and MCP tool: Amazon search volume for up to 10,000 keywords, related Amazon keywords, and reverse ASIN (keywords a product ranks for, with its rank). Volume: 16 markets. Pay $0.0006 per keyword with data + a $0.03 fee per batch, seed or ASIN.

Typical uses

  • Check the Amazon search volume of your listing keywords before writing a title, bullets or backend search terms.
  • Find long-tail Amazon keywords around a product idea (related keywords, up to 1,000 per seed).
  • Reverse ASIN a competitor: see which searches bring its traffic and where it ranks, then target the same keywords.
  • Size a niche: total monthly Amazon searches for a list of product keywords, per country.
  • Feed keyword data into Google Sheets, n8n / Make workflows or an AI agent.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~amazon-keyword-research/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "phone case",
    "iphone charger",
    "wireless earbuds"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/amazon-keyword-research").call(run_input={'keywords': ['phone case', 'iphone charger', 'wireless earbuds']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
