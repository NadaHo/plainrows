Typical uses

  • Lead generation and sales prospecting: find every Shopify, WooCommerce or Magento store in a list, or every company on HubSpot, Salesforce or Microsoft 365, with the e-mail, phone and LinkedIn page their homepage shows.
  • Agencies: qualify prospects by CMS (WordPress, Webflow, Wix, Squarespace), page builder or analytics setup before a pitch.
  • Competitive and market research: measure the market share of a CMS, a payment provider or a chat tool across thousands of sites.
  • SaaS go-to-market: build lists of sites using a competitor's product (e.g. Intercom, Klaviyo, Optimizely).
  • Security and IT inventory: see which web servers, frameworks and versions your own sites expose.
  • Automations and AI agents: enrich a CRM or a Google Sheet with the tech stack of each account.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~website-tech-stack/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "shopify.com",
    "wordpress.org",
    "nextjs.org"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/website-tech-stack").call(run_input={'domains': ['shopify.com', 'wordpress.org', 'nextjs.org']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
