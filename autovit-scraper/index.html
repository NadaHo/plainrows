Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~autovit-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "dacia duster",
    "https://www.autovit.ro/autoturisme/volkswagen/golf?search%5Bfilter_float_year%3Afrom%5D=2018"
  ],
  "maxResultsPerSearch": 32
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/autovit-scraper").call(run_input={'searches': ['dacia duster',
              'https://www.autovit.ro/autoturisme/volkswagen/golf?search%5Bfilter_float_year%3Afrom%5D=2018'],
 'maxResultsPerSearch': 32})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
