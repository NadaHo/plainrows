How it works

  • Every tool runs on Apify: one account, one API token, the same API for every tool.
  • Prices are shown up front on each tool's pricing table. Rows with no data and invalid inputs are not billed; tools with a fixed fee per search say so.
  • Missing values are returned as null, never guessed.
