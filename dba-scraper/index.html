Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~dba-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "iphone",
    "https://www.dba.dk/recommerce/forsale/search?q=iphone&price_to=5000"
  ],
  "maxResultsPerSearch": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/dba-scraper").call(run_input={'searches': ['iphone',
              'https://www.dba.dk/recommerce/forsale/search?q=iphone&price_to=5000'],
 'maxResultsPerSearch': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
