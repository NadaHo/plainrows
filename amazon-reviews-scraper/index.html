Amazon Reviews Scraper: Ratings, Text & Dates

Paste amazon.com ASINs or product URLs, get the top customer reviews shown on each product page: rating, title, text, date, country, verified purchase, helpful votes. No login. Pay per review plus small product and start fees.

Try it on Apify  

Typical uses

  • Product research for Amazon sellers, FBA and dropshipping: what buyers like and complain about, before you source a product.
  • Competitor watch: schedule a run with "Only new reviews" and get each new top review of your competitors' products.
  • Critical reviews only: set the rating range to 1-2 stars to collect complaints for product improvement.
  • Sentiment analysis and AI: clean review text for an LLM, Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~amazon-reviews-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "products": [
    "0593139135",
    "https://www.amazon.com/dp/B0BSHF7WHW"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/amazon-reviews-scraper").call(run_input={'products': ['0593139135', 'https://www.amazon.com/dp/B0BSHF7WHW']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
