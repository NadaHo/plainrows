  • Local SEO: see who ranks in the Google Maps pack for a query, with rating, review count and claimed status.
  • Market research: count and map competitors, franchises or points of sale in an area.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-maps-businesses/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "coffee shop in Austin, TX"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-maps-businesses").call(run_input={'searchQueries': ['coffee shop in Austin, TX'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
