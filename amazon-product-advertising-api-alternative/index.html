Amazon search data without the Product Advertising API

You want Amazon search results inside a script, a spreadsheet, n8n or an AI agent: which products rank for a keyword, their ASIN, price, rating, number of reviews and badges. Here is where Amazon's own API stands, and what PlainRows offers.

Amazon's API and its conditions

From Amazon's Associates documentation on 2026-10-08:

  • PA-API 5 is deprecated: "The Amazon Product Advertising API 5.0 (PA-API 5) has been deprecated and is being replaced by the Creators API", and "Applications that continue to call PA-API 5 receive an HTTP 403 Forbidden response" (PA-API 5 deprecation).
  • Creators API eligibility: you must "Be enrolled in the Amazon Associates program for your target marketplace" and "Have at least 10 qualifying sales within the past 30 days" (Creators API introduction). It is part of the affiliate program: access depends on the sales you send to Amazon.

When Amazon's API is the better choice

  • You are an active Associate with the required sales and you link to Amazon to earn commissions: the API is made for that.
  • You need full product details for known ASINs (all images, feature bullets, variations, offers). PlainRows returns what the search results page shows.

When PlainRows is the better choice

  • You do product or niche research, price monitoring or Amazon SEO, with or without an Associates account.
  • You want the ranking for a keyword as shoppers see it: organic rank, sponsored placements, badges and "bought in past month".
  • You run it from n8n, Make, Zapier, Google Sheets or an AI agent (MCP), with a hard cap: every run stops at the maximum cost you set.
