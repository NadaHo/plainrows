Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~twitch-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "mode": "channels",
  "channels": [
    "shroud",
    "pokimane"
  ],
  "maxResults": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/twitch-scraper").call(run_input={'mode': 'channels', 'channels': ['shroud', 'pokimane'], 'maxResults': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
