PlainRows

YouTube comments as rows, without a Google Cloud project

You want to know what viewers say under your videos, a competitor's launch or a product review: for sentiment analysis, an AI summary or a daily list of questions to answer. You do not want to set up an API project and write paging code.

What you get per comment

Give YouTube links (watch, youtu.be, Shorts) or video IDs to YouTube Comments Scraper. Each comment is one row: text, likes, number of replies, date, plus the video's ID, title, link and total comment count. You get the top and recent comments, up to 700 per video; replies themselves are not included, and comment authors' names and channel links are not collected. Videos found with YouTube Search Scraper can be passed as they are (their url or videoId column). With Only new comments and a daily schedule, each run returns only comments it has not delivered before.

Real example, checked on 2026-10-11: 100 comments of a sourdough baking video with 3,254 comments, ready in about 20 seconds.

Other ways to get the same data

  • YouTube Data API v3: commentThreads.list returns up to 100 comment threads per call, with replies, for "a quota cost of 1 unit" per call (reference); projects get 10,000 units a day by default (getting started). It is free and gives every comment, but you need a Google Cloud project, credentials and your own paging code; videos with comments turned off answer with a commentsDisabled error. Best if you code and need all comments or the replies.
  • YouTube Studio: shows the comments of your own channel, to read and reply by hand. Best for a few videos of your own.
