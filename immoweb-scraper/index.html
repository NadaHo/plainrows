Immoweb Scraper: Belgium Property Listings & Prices

Belgium real estate scraper and MCP tool: paste immoweb.be search URLs, get every listing: price, type, bedrooms, living area, energy class (EPC), locality, postal code, agency, date. Houses, flats, land, buy or rent. No login. Pay per listing plus a small start fee per run.

Typical uses

  • Investors and analysts: asking prices and price per m² by municipality and postal code, every week (schedule a run).

  • Energy renovation leads and studies: share of EPC classes E, F and G by area.
  • Spreadsheets, BI and AI agents: clean rows for Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~immoweb-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "https://www.immoweb.be/en/search/apartment/for-sale/brussels/1000",
    "https://www.immoweb.be/en/search/house/for-rent/antwerp/2000"
  ],
  "maxResultsPerSearch": 30
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/immoweb-scraper").call(run_input={'searches': ['https://www.immoweb.be/en/search/apartment/for-sale/brussels/1000',
              'https://www.immoweb.be/en/search/house/for-rent/antwerp/2000'],
 'maxResultsPerSearch': 30})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
