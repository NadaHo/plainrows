Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-maps-rank-tracker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "business": "Monmouth Coffee Company, Borough, London",
  "keywords": [
    "coffee shop"
  ],
  "gridSize": "3",
  "country": "GB"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-maps-rank-tracker").call(run_input={'business': 'Monmouth Coffee Company, Borough, London',
 'keywords': ['coffee shop'],
 'gridSize': '3',
 'country': 'GB'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
