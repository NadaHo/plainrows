Greenhouse Jobs Scraper: Any Greenhouse Job Board

Greenhouse jobs scraper and MCP tool: every open job from any Greenhouse board via its public API: title, department, locations, remote, salary when published, posted date, apply link and description. Paste the board URL, its name or the company website. Pay per job plus a small start fee.

Typical uses

  • Job boards and aggregators: fill a niche board with fresh jobs straight from the thousands of startups and tech companies that hire through Greenhouse.
  • Sales and recruiting intelligence: which target accounts are hiring, for which teams, in which cities.
  • Market and talent research: count openings per department, follow hiring trends, compare published salary ranges across companies.
  • Job seekers and career tools: watch a list of companies for new roles matching your keywords or locations. With Only new jobs on, a scheduled run returns (and bills) only jobs it has never delivered.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets, Airtable or an MCP client with structured JSON.

Ready-to-run examples

  • Export all open jobs from a Greenhouse job board: Get every open job a company posts on Greenhouse with title, department, locations, remote flag, salary range when published, posting date, apply link and the full description.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~greenhouse-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "companies": [
    "https://job-boards.greenhouse.io/airbnb",
    "https://boards.greenhouse.io/figma",
    "stripe"
  ],
  "maxJobsPerCompany": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/greenhouse-jobs-scraper").call(run_input={'companies': ['https://job-boards.greenhouse.io/airbnb',
               'https://boards.greenhouse.io/figma',
               'stripe'],
 'maxJobsPerCompany': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
