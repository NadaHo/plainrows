Workday Jobs Scraper: Any myworkdayjobs Careers Site

Get every open job from any Workday careers site (myworkdayjobs.com, myworkdaysite.com): title, locations, country, remote flag, posted date, employment type, apply link and full description. Paste the careers page URL or the company website. Only-new-jobs mode. Pay per job.

Try it on Apify  

Typical uses

  • Job boards and aggregators: fill a niche board with fresh jobs straight from large employers that hire through Workday.
  • Sales and recruiting intelligence: which target accounts are hiring, for which roles, in which countries.
  • Market and talent research: count openings per country or role, follow hiring trends at Fortune 500 companies.
  • Job seekers and career tools: watch a list of companies for new roles matching your keywords or locations. With Only new jobs on, a scheduled run returns (and bills) only jobs it has never delivered.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets, Airtable or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~workday-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "companies": [
    "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite",
    "https://salesforce.wd12.myworkdayjobs.com/External_Career_Site",
    "https://adobe.wd5.myworkdayjobs.com/external_experienced"
  ],
  "maxJobsPerCompany": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/workday-jobs-scraper").call(run_input={'companies': ['https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite',
               'https://salesforce.wd12.myworkdayjobs.com/External_Career_Site',
               'https://adobe.wd5.myworkdayjobs.com/external_experienced'],
 'maxJobsPerCompany': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
