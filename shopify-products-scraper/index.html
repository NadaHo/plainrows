Shopify Scraper: Products, Prices, Variants & Stock

Shopify scraper and MCP tool: products, prices, compare-at prices, stock, variants with SKU, options, images, tags and descriptions from any Shopify store, collection or product URL. Reads the store's public product feed. Pay per product + start fee.

Try it on Apify  

Typical uses

  • Competitor price monitoring: the prices, sales (compare-at price) and stock of a competitor's whole catalog, every day.
  • Product research and dropshipping: what a store sells, its best price points, its newest products (the feed lists newest first).
  • Catalog export: a full product list with SKUs for a migration, a marketplace feed or a spreadsheet.
  • AI agents: ask an agent "what does store X sell under $50 and what is on sale?" and let it call this Actor through Apify's MCP server.

Ready-to-run examples

  • Export a Shopify store's products, prices and stock: Paste Shopify store domains or collection URLs (here Allbirds and ColourPop lip products) and get every product with price, compare-at price, stock, variants with SKU, options, images, tags and description. No login or API key.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~shopify-products-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "startUrls": [
    "allbirds.com",
    "https://www.colourpop.com/collections/lips"
  ],
  "maxProductsPerInput": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/shopify-products-scraper").call(run_input={'startUrls': ['allbirds.com', 'https://www.colourpop.com/collections/lips'],
 'maxProductsPerInput': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
