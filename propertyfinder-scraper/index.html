Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~propertyfinder-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "https://www.propertyfinder.ae/en/buy/dubai/apartments-for-sale.html",
    "https://www.propertyfinder.ae/en/rent/abu-dhabi/villas-for-rent.html"
  ],
  "maxResultsPerSearch": 25
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/propertyfinder-scraper").call(run_input={'searches': ['https://www.propertyfinder.ae/en/buy/dubai/apartments-for-sale.html',
              'https://www.propertyfinder.ae/en/rent/abu-dhabi/villas-for-rent.html'],
 'maxResultsPerSearch': 25})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
