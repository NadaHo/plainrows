Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~coches-net-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "seat leon",
    "https://www.coches.net/segunda-mano/volkswagen/golf/"
  ],
  "maxResultsPerSearch": 40
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/coches-net-scraper").call(run_input={'searches': ['seat leon',
              'https://www.coches.net/segunda-mano/volkswagen/golf/'],
 'maxResultsPerSearch': 40})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
