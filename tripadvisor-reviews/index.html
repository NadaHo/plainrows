Tripadvisor Reviews Scraper API: Hotels & Restaurants

Get Tripadvisor reviews of hotels, restaurants and attractions: stars, title, text, visit date, photos, management response and the place rating. Paste Tripadvisor links. No reviewer names. Only-new-reviews mode for alerts. Pay per review plus small fetch and start fees.

Try it on Apify  

Typical uses

  • Hotel and restaurant reputation monitoring: turn on Only new reviews, schedule a daily run and send new 1- and 2-star reviews to Slack or a spreadsheet: you never get (or pay for) the same review twice.
  • Competitor benchmarking: compare ratings, complaints and response rates of the hotels or restaurants around you.
  • Travel and hospitality research: what guests praise or complain about, by traveler type (families, couples, business) or month of visit.
  • Sentiment analysis and AI summaries: feed clean review text to an LLM, a BI tool or an AI agent (MCP).
  • Agencies: monthly review reports for hospitality clients.

Ready-to-run examples

  • Read a hotel's 1- and 2-star Tripadvisor reviews: Get the poor and terrible Tripadvisor reviews of a hotel, newest first: what guests complain about, with title, text, visit date and the management response. Change the link to any hotel, restaurant or attraction.
  • Get new Tripadvisor reviews of your hotel or restaurant daily: Schedule this task daily: each run returns only the Tripadvisor reviews posted since the last run, with stars, text and management response, so you can answer unhappy guests fast. Pay only for new reviews.
  • Export Tripadvisor reviews from business travelers: Export the latest Tripadvisor reviews written by business travelers for a hotel: stars, title, text, visit date and photos, for a guest-feedback report or sentiment analysis.

Guides and comparisons

  • Tripadvisor reviews API: all reviews, not just 5
  • Trustpilot reviews API: new reviews of any company, per review

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~tripadvisor-reviews/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "startUrls": [
    "https://www.tripadvisor.com/Hotel_Review-g60763-d23462501-Reviews-Margaritaville_Times_Square-New_York_City_New_York.html"
  ],
  "maxReviewsPerPlace": 100
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/tripadvisor-reviews").call(run_input={'startUrls': ['https://www.tripadvisor.com/Hotel_Review-g60763-d23462501-Reviews-Margaritaville_Times_Square-New_York_City_New_York.html'],
 'maxReviewsPerPlace': 100})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
