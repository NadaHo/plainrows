Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~aliexpress-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "wireless earbuds",
    "https://www.aliexpress.com/w/wholesale-phone-case.html"
  ],
  "maxResultsPerSearch": 60
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/aliexpress-scraper").call(run_input={'searches': ['wireless earbuds',
              'https://www.aliexpress.com/w/wholesale-phone-case.html'],
 'maxResultsPerSearch': 60})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
