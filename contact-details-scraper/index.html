Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~contact-details-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "russanddaughters.com",
    "levainbakery.com",
    "bigsurbakery.com",
    "voodoodoughnut.com"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/contact-details-scraper").call(run_input={'domains': ['russanddaughters.com',
             'levainbakery.com',
             'bigsurbakery.com',
             'voodoodoughnut.com']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
