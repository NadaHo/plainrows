Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~keyword-suchvolumen/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "kaffeemaschine",
    "siebtr\u00e4germaschine",
    "kaffeevollautomat"
  ],
  "mode": "volume",
  "country": "DE"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/keyword-suchvolumen").call(run_input={'keywords': ['kaffeemaschine', 'siebträgermaschine', 'kaffeevollautomat'],
 'mode': 'volume',
 'country': 'DE'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
