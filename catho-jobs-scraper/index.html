Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~catho-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchUrls": [
    "https://www.catho.com.br/vagas/vendedor/"
  ],
  "keywords": [
    "analista de dados"
  ],
  "locations": [
    "S\u00e3o Paulo, SP"
  ],
  "maxResultsPerSearch": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/catho-jobs-scraper").call(run_input={'searchUrls': ['https://www.catho.com.br/vagas/vendedor/'],
 'keywords': ['analista de dados'],
 'locations': ['São Paulo, SP'],
 'maxResultsPerSearch': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
