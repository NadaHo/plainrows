PlainRows

Google Maps Reviews Scraper

Google Maps reviews scraper and MCP tool: stars, text, date, translation, photos, owner reply and the place's rating for any place. Paste Maps links, place IDs, CIDs or names. No reviewer names. Only-new-reviews mode for daily alerts. Pay per review plus small fetch and start fees.

Try it on Apify  

Typical uses

  • Reputation monitoring: turn on Only new reviews, schedule a daily run and send new 1- and 2-star reviews to Slack or a spreadsheet: you never get (or pay for) the same review twice.
  • Local SEO and agencies: check review volume, rating and owner reply rate for your clients and their competitors.
  • Lead qualification: chain it after a Google Maps search (see below) to find businesses with unanswered complaints.
  • Sentiment analysis and AI summaries: feed clean review text (translated into one language, original kept) to an LLM, a BI tool or an AI agent (MCP).
  • Market research: compare what customers praise or complain about across a city's restaurants, hotels, clinics or shops.

Ready-to-run examples

  • Read a competitor's 1-star Google reviews: Get the lowest-rated Google Maps reviews of a business, worst first: what customers complain about, with the text, date and the owner's reply. Change the place to any competitor.
  • Get new Google reviews of your locations every day: Schedule this task daily: each run returns only the reviews posted since the last run, with stars, text and owner reply, so you can answer unhappy customers fast. Pay only for new reviews.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-maps-reviews/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "places": [
    "ChIJifIePKtZwokRVZ-UdRGkZzs"
  ],
  "maxReviewsPerPlace": 100,
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-maps-reviews").call(run_input={'places': ['ChIJifIePKtZwokRVZ-UdRGkZzs'],
 'maxReviewsPerPlace': 100,
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
