Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~otodom-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "https://www.otodom.pl/pl/wyniki/sprzedaz/mieszkanie/mazowieckie/warszawa",
    "https://www.otodom.pl/pl/wyniki/wynajem/mieszkanie/malopolskie/krakow"
  ],
  "maxResultsPerSearch": 36
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/otodom-scraper").call(run_input={'searches': ['https://www.otodom.pl/pl/wyniki/sprzedaz/mieszkanie/mazowieckie/warszawa',
              'https://www.otodom.pl/pl/wyniki/wynajem/mieszkanie/malopolskie/krakow'],
 'maxResultsPerSearch': 36})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
