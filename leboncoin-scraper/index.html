Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~leboncoin-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "https://www.leboncoin.fr/recherche?text=velo"
  ],
  "maxResultsPerSearch": 35
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/leboncoin-scraper").call(run_input={'searches': ['https://www.leboncoin.fr/recherche?text=velo'],
 'maxResultsPerSearch': 35})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
