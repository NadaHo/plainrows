Typical uses

  • AI agents and RAG: give an LLM fresh Google results (URL, title, snippet) as an MCP tool, then let it read the pages it needs.
  • SEO: see who ranks on Google for your keywords, by country and language, desktop or mobile.
  • Research and monitoring: collect the top Google results for a list of topics, brands or questions on a schedule.
  • Lead and content discovery: find the sites, articles and forums Google shows for a topic.
  • Exports: send the rows to Google Sheets, BigQuery, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-search-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "crm software",
    "best project management tool"
  ],
  "country": "US",
  "device": "desktop",
  "maxResults": 10
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-search-api").call(run_input={'queries': ['crm software', 'best project management tool'],
 'country': 'US',
 'device': 'desktop',
 'maxResults': 10})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
