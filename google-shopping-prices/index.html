Typical uses

  • Price monitoring: track your products' and competitors' prices on Google Shopping every day, with discounts and old prices.

  • Product and market research: which brands, models and sellers show up for a category, at which price points and ratings.
  • Repricing and MAP checks: spot sellers below your minimum advertised price, by store domain.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-shopping-prices/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "sony wh-1000xm5"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-shopping-prices").call(run_input={'searchQueries': ['sony wh-1000xm5'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
