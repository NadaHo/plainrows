Get Google Images results as clean data: original image URL, thumbnail, title, source page and domain, position. Filter by size, color, type, file type, date and usage rights, 20 countries. Fast API, no browser. Pay only per image found.

Typical uses

  • Dataset building for machine learning: collect image URLs and their source pages per label (`golden retriever`, `oak leaf`), with Creative Commons or file type filters, then download them yourself under each license.
  • Image SEO: see which pages and domains rank in Google Images for your keywords, and at which position; track your own images.
  • Visual SERP tracking: schedule the same queries daily or weekly and compare positions and sources over time, per country.
  • Content and design research: find reference images, transparent PNGs, SVG icons or Creative Commons photos for a topic, with the page to credit.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-images-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "red bicycle"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-images-scraper").call(run_input={'searchQueries': ['red bicycle'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
