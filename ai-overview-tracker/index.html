AI Overview tracker, AI Overview API and MCP tool: for each keyword, see if Google shows an AI Overview, if it cites your domain (rank, URL), which sites it cites, and your organic rank. Pay per keyword, plus a fee per AI Overview found.

Try it on Apify  

Typical uses

  • AI Overview citation tracking (AEO / GEO): which of your target keywords trigger an AI Overview, and are you one of its sources?
  • AI Overview vs organic rank: spot keywords where you rank in the top 3 but are not cited, or are cited without ranking.
  • Competitor research: `citedDomains` shows which sites Google's AI relies on for your topics: the pages to beat or to get mentioned on.
  • Bulk check of a keyword list: find which keywords show an AI Overview at all, before you invest in content.
  • Weekly reports: schedule a run and send the table to Google Sheets, Looker Studio, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~ai-overview-tracker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domain": "hubspot.com",
  "keywords": [
    "what is a crm",
    "best crm for small business",
    "how to write a sales email"
  ],
  "brandNames": [
    "HubSpot"
  ],
  "country": "US",
  "depth": 10
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/ai-overview-tracker").call(run_input={'domain': 'hubspot.com',
 'keywords': ['what is a crm',
              'best crm for small business',
              'how to write a sales email'],
 'brandNames': ['HubSpot'],
 'country': 'US',
 'depth': 10})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
