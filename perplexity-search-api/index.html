Typical uses

  • AI search visibility (GEO / AEO): is your brand named, is your site cited, at which rank, for the questions your buyers ask?

  • Answers with sources for your app or agent: Perplexity search as plain JSON, with the citations kept apart from the text.
  • Weekly reports: schedule a run and send the rows to Google Sheets, Looker Studio, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~perplexity-search-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "What is the best CRM for small businesses?",
    "Which project management tools do agencies recommend?"
  ],
  "country": "US",
  "maxOutputTokens": 800
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/perplexity-search-api").call(run_input={'queries': ['What is the best CRM for small businesses?',
             'Which project management tools do agencies recommend?'],
 'country': 'US',
 'maxOutputTokens': 800})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
