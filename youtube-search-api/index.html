YouTube Search API: Videos, Views & Channels as JSON

YouTube Search API and MCP tool: search results as JSON for any keyword: video title, URL, views, channel, duration, upload date and position. Date, length, Shorts and live filters. No API key, no quota. Pay per video plus a small start fee; only-new-videos mode adds a fee per 20 results checked.

Try it on Apify  

Typical uses

  • Search YouTube from your app or backend: send keywords, get videos with views, channel, duration and date as JSON, without the default quota of the official API (about 100 searches a day).
  • YouTube SEO and rank tracking: schedule the same queries daily or weekly and track the `position` of your videos and your competitors'.
  • Monitoring new videos: turn on Only new videos and schedule the run to get (and pay for) each new upload about a brand, product or topic once.
  • Influencer and channel discovery: find the channels that publish on a topic, with their channel ID and URL.
  • Datasets for analysis and AI agents: titles, descriptions, durations and view counts as JSON for spreadsheets, BI tools or LLM pipelines.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~youtube-search-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "how to make sourdough bread"
  ],
  "maxResultsPerQuery": 20,
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/youtube-search-api").call(run_input={'searchQueries': ['how to make sourdough bread'],
 'maxResultsPerQuery': 20,
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
