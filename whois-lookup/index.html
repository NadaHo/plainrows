WHOIS Lookup: Bulk Domain Age, Expiry & Availability Checker

WHOIS lookup and MCP tool for any list of domains: registrar, creation and expiry dates, domain age, days until expiry, status, name servers, DNSSEC, and whether the domain is registered. RDAP first, WHOIS for .de, .io, .co, .it. Pay per domain plus a small start fee per run.

Try it on Apify  

Typical uses

  • SEO and link building: check the age and expiry date of domains before buying links or an expired domain.
  • Domain investing and brand protection: see which names in a list are free, which expire soon, and who the registrar is.
  • Lead qualification and fraud checks: flag very young domains (a few days old) in sign-ups, shops or e-mails.
  • IT and security inventory: list the expiry dates, registrars, DNSSEC and name servers of all your company's domains, and catch renewals before they lapse.
  • Automations and AI agents: enrich a CRM, a Google Sheet or an n8n / Make / Zapier flow with domain age and expiry.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~whois-lookup/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "apify.com",
    "wikipedia.org",
    "bbc.co.uk",
    "spiegel.de",
    "example-domain-not-registered-123.com"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/whois-lookup").call(run_input={'domains': ['apify.com',
             'wikipedia.org',
             'bbc.co.uk',
             'spiegel.de',
             'example-domain-not-registered-123.com']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
