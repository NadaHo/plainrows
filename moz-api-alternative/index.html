A Moz API alternative for bulk domain authority checks

You need an authority score and a spam score for a list of domains (link building, outreach lists, SEO audits), inside a script, a spreadsheet, n8n or an AI agent. Here is what the Moz API plans include, and what PlainRows charges.

What the Moz API plans include

From moz.com/products/api/pricing on 2026-10-08 (the page showed a limited-time discount banner that day):

  • Free: up to 50 rows per month, one request every ten seconds.
  • Starter: $20 per month for 3,000 rows (no overage), or $75 per month for 15,000 rows ($5 per extra 1,000 rows).
  • Growth: $125 per month for 50,000 rows, $250 for 120,000 rows, $500 for 500,000 rows, with overage per 10,000 rows.
  • Rows measure the cost of each request: Moz says the endpoint and parameters determine how many rows a call uses.

When the Moz API is the better choice

  • You need Moz Domain Authority (DA) or Moz Spam Score themselves, for example because a client asks for DA. PlainRows returns DataForSEO's domain rank and spam score, from a different backlink index: values will not match Moz's.
  • You check a few dozen domains a month: the free Moz plan may be enough.
  • You need Moz's other endpoints (URL metrics history, link status, keyword data) through one API.

When PlainRows is the better choice

  • You check large lists now and then (thousands of domains in one run) and do not want a monthly row budget.
  • You want results in n8n, Make, Zapier, Google Sheets or an AI agent (MCP) and to pay only for domains with data.
