Germany jobs scraper and MCP tool: German jobs from the official Arbeitsagentur Jobbörse API by keyword + place: title, company, address, occupation, full/part-time, remote, salary when given, dates, link. No login. Pay per job ($0.0009 or less) plus a $0.001 start fee per run.

Typical uses

  • German job market research: how many data, nursing, logistics or engineering jobs are open in Berlin, Munich or Hamburg, with which salary and working time.
  • Recruitment agencies and sales teams: which German companies are hiring, for what, where (lead lists with company and work address).
  • Job boards and alerts: feed new German jobs into your own site, Slack, Google Sheets or an AI agent every day (`publishedWithinDays: 1`).
  • Salary and remote analysis: share of ads with a salary range, of part-time or home-office jobs in your field.
  • Spreadsheets, BI and AI agents: clean rows for Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~arbeitsagentur-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "Data Engineer"
  ],
  "locations": [
    "Berlin"
  ],
  "maxJobsPerSearch": 150
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/arbeitsagentur-jobs-scraper").call(run_input={'keywords': ['Data Engineer'],
 'locations': ['Berlin'],
 'maxJobsPerSearch': 150})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
