Typical uses

  • AI search visibility (GEO / AEO): which sites does ChatGPT cite, which brands and products does it recommend, for the prompts your buyers type?
  • Citation research: `sources` and `citedDomains` show the pages ChatGPT relies on; `searchResults` shows what it read but did not cite.
  • Query research: `fanOutQueries` shows the web searches ChatGPT ran behind one prompt: keywords to target.
  • Answers with sources for your app or agent: ChatGPT search as plain JSON, with the citations kept apart from the text.
  • Weekly reports: schedule a run and send the rows to Google Sheets, Looker Studio, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~chatgpt-search-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "prompts": [
    "best standing desk for small spaces",
    "Which CRM do small agencies recommend in 2026?"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/chatgpt-search-scraper").call(run_input={'prompts': ['best standing desk for small spaces',
             'Which CRM do small agencies recommend in 2026?'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
