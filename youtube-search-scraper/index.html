YouTube search scraper, YouTube rank tracker and YouTube keyword research tool: video title, URL, views, upload date, duration, channel and position for any keyword. Date, length, Shorts and live filters; only-new-videos alerts. A YouTube Data API alternative: no API key, no quota. Pay per video.

Try it on Apify  

Typical uses

  • Keyword and topic research for creators: see which videos rank for a keyword, how many views they have and how old they are.
  • YouTube SEO and rank tracking: schedule the same queries daily or weekly and track the `position` of your videos and your competitors'.
  • Monitoring new videos: turn on Only new videos and schedule the run to get (and pay for) each new upload about a brand, product or topic once.
  • Influencer and channel discovery: find the channels that publish on a topic, with their channel ID and URL.
  • Datasets for analysis and AI: titles, descriptions, durations and view counts as clean JSON for spreadsheets, BI tools or LLM pipelines.

Ready-to-run examples

  • Get YouTube videos for a keyword with views: Search YouTube and export videos with title, URL, channel, views, upload date and duration, without an API key or quota.
  • Most viewed YouTube videos this week on a topic: Find the most popular YouTube videos uploaded this week for a topic, sorted by views, Shorts excluded.
  • Find long YouTube tutorials (20+ minutes): List long-form YouTube tutorials (over 20 minutes) on any subject, with channel and view counts.
  • Get only new YouTube videos about a topic or brand: Schedule this task daily: the first run lists this week's videos, each later run returns only videos it has never delivered, so you pay once per video. Send them to Slack or a sheet.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~youtube-search-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "how to make sourdough bread"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/youtube-search-scraper").call(run_input={'searchQueries': ['how to make sourdough bread'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
