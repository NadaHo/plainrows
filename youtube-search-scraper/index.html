Get YouTube search results for any keyword: video title, URL, views, upload date, duration, channel, badges and position. Filters for date, length, Shorts and live. Results in seconds, no browser, no API key. Pay only per video found.

Typical uses

  • Keyword and topic research for creators: see which videos rank for a keyword, how many views they have and how old they are.
  • YouTube SEO and rank tracking: schedule the same queries daily or weekly and track the `position` of your videos and your competitors'.
  • Monitoring new videos: `uploadDate: "today"` or `"week"` to catch new uploads about a brand, product or topic.
  • Influencer and channel discovery: find the channels that publish on a topic, with their channel ID and URL.
  • Datasets for analysis and AI: titles, descriptions, durations and view counts as clean JSON for spreadsheets, BI tools or LLM pipelines.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~youtube-search-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "how to make sourdough bread"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/youtube-search-scraper").call(run_input={'searchQueries': ['how to make sourdough bread'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
