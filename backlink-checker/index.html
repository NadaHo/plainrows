Backlink Checker API: Backlinks, Referring Domains & Anchors

Check the backlinks of any domain or URL: source page, anchor text, dofollow, domain rank, spam score, first and last seen. Or list its referring domains with link counts. Up to 10,000 rows per target, no Ahrefs or Semrush subscription. Pay only per result.

Try it on Apify  

Typical uses

  • Competitor backlink research: see which sites link to a competitor, with which anchor, and which links pass authority (dofollow).
  • Link building prospecting: list the referring domains of competing pages, sorted by rank, and contact the best ones.
  • Backlink audits: spot spammy, broken, lost or nofollow links pointing to your site.
  • New link monitoring: sort by newest to see links found recently; schedule the run weekly.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~backlink-checker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "targets": [
    "backlinko.com"
  ],
  "maxResultsPerTarget": 100
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/backlink-checker").call(run_input={'targets': ['backlinko.com'], 'maxResultsPerTarget': 100})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
