Competitor Keywords API: Ranked Keywords of Any Domain

Competitor keywords finder and MCP tool: every keyword a domain ranks for on Google (ranked keywords, domain keywords) with position, ranking URL, volume, CPC, difficulty and intent, plus organic traffic. Bulk domains, 94 countries. From $0.002 per keyword, plus per-domain and $0.012 start fees.

Try it on Apify  

Typical uses

  • Find the keywords a competitor ranks for, and on which page, to plan your own content.
  • Keyword gap by hand: export the ranked keywords of 3 competitors and keep those you don't rank for.
  • Spot a site's best traffic keywords and quick wins (positions 4-20 with high volume, using `maxPosition` and `minSearchVolume`).
  • Check the domain keywords of prospects, partners or acquisition targets in bulk.
  • Track ranking keywords over time by scheduling runs.
  • Give AI agents (MCP) a competitor keywords tool: one call returns the keywords of a domain with their metrics.
  • Need the Google Ads keywords instead? Set `keywordType` to `paid` (same price).

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~competitor-keywords-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "backlinko.com"
  ],
  "country": "US",
  "topKeywords": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/competitor-keywords-api").call(run_input={'domains': ['backlinko.com'], 'country': 'US', 'topKeywords': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
