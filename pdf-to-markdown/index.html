Typical uses

  • RAG and knowledge bases: feed research papers, manuals, reports and documentation into a vector store as Markdown, page by page.
  • AI agents (MCP): let an agent read a PDF it found on the web in one tool call.
  • Summaries and extraction: give an LLM the Markdown of contracts, filings, datasheets or whitepapers.
  • Search and archiving: index the full text of public PDFs with their page count and word count.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~pdf-to-markdown/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "urls": [
    "https://arxiv.org/pdf/1706.03762",
    "https://www.irs.gov/pub/irs-pdf/fw9.pdf"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/pdf-to-markdown").call(run_input={'urls': ['https://arxiv.org/pdf/1706.03762',
          'https://www.irs.gov/pub/irs-pdf/fw9.pdf']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
