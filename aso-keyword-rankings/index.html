Typical uses

  • ASO keyword research: see which apps own a keyword before you target it, and how strong they are (ratings, ratings count).
  • Rank tracking: re-run on a schedule and follow the rank of your app and your competitors for your keywords.
  • Competitor discovery: list every app that shows up for the words your users type.
  • Country checks: compare the ranking for the same keyword in the US, UK, Germany, Brazil or Japan.
  • AI agents: let an assistant answer "which apps rank first for budget app on the App Store?".
  • Exports: send the rows to Google Sheets, Notion, BigQuery, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~aso-keyword-rankings/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "habit tracker"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/aso-keyword-rankings").call(run_input={'keywords': ['habit tracker']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
