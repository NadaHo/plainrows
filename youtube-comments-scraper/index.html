YouTube Comments Scraper: Video Comments Export

YouTube comments scraper, API and MCP tool: export the comments of any video with text, likes, reply count, date, video title and comment count. Paste video links, Shorts links or IDs. Top and recent comments, up to 700 per video. No author names. Pay per comment plus small fetch and start fees.

Try it on Apify  

Typical uses

  • Sentiment analysis and AI summaries: feed clean comment text to an LLM, a BI tool or an AI agent (MCP) to see what viewers like, ask and complain about.
  • Product and brand research: read the comments under product reviews, launches and ads, yours or your competitors'.
  • Creators and social media teams: turn on Only new comments, schedule a daily run and get the new comments on your videos, never the same one twice, in Slack or a spreadsheet.
  • Content ideas: collect the questions viewers ask under the top videos of your niche.

Ready-to-run examples

  • Export YouTube comments of a video for sentiment analysis: Get the top and recent comments of a YouTube video with text, likes, reply count and date, ready for sentiment analysis, an LLM summary or a spreadsheet. No author names.
  • Get new comments on your YouTube videos every day: Schedule this task daily: each run returns only comments posted since the last run on your videos, so you can answer viewers fast. Pay only for new comments.
  • Read the comments on competitors' YouTube videos: Collect the comments of several competing YouTube videos on the same topic: what viewers ask, praise or complain about, with likes and reply counts.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~youtube-comments-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "videos": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ],
  "maxCommentsPerVideo": 100
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/youtube-comments-scraper").call(run_input={'videos': ['https://www.youtube.com/watch?v=dQw4w9WgXcQ'],
 'maxCommentsPerVideo': 100})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
