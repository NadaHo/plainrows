Google Trends keyword discovery and MCP tool: find new keywords from rising and top related queries and topics for any seed keyword, with growth %, plus interest over time. Any country, web, YouTube or Shopping search. No proxies. $0.006 per search + $0.002 per run start; fast mode extra.

Typical uses

  • Keyword discovery for SEO and content: rising queries around a topic before they show up in keyword tools, for articles, videos and landing pages.
  • Trend spotting: which products, brands or questions are breaking out right now, by country and by search type (web, YouTube, Shopping).
  • Keyword research seeds: feed the rising and top queries to [Keyword Search Volume](https://apify.com/plainrows/keyword-search-volume) to get monthly volume, CPC and difficulty.
  • Ads and e-commerce: new search terms to add to campaigns, seasonal demand to plan stock and budgets.
  • Automations and AI agents: a daily or weekly list of rising keywords to Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-trends-keyword-discovery/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchTerms": [
    "coffee",
    "ai agents"
  ],
  "country": "US",
  "timeRange": "past_12_months"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-trends-keyword-discovery").call(run_input={'searchTerms': ['coffee', 'ai agents'],
 'country': 'US',
 'timeRange': 'past_12_months'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
