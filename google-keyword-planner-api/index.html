Google Keyword Planner API and MCP tool: real Google Ads search volume, CPC, competition, top-of-page bids and 12-month trend for up to 10,000 keywords, long tail included. A keyword planner alternative without an Ads account. Fee per 1,000-keyword lookup + per keyword found.

Try it on Apify  

Typical uses

  • Bulk search volume: check thousands of keywords in one run, 1,000 per lookup.
  • Long-tail and local-language research: real Google Ads data for phrases too rare for SEO tools.
  • PPC planning: `cpc`, `lowTopOfPageBid` and `highTopOfPageBid` to budget a Google Ads campaign.
  • Seasonality: `monthlySearches` shows the last 12 months, month by month.
  • AI agents and automations: one JSON row per keyword, ready for Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-keyword-planner-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "coffee maker",
    "espresso machine",
    "french press"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-keyword-planner-api").call(run_input={'keywords': ['coffee maker', 'espresso machine', 'french press'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
