Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~gupy-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchUrls": [
    "https://portal.gupy.io/job-search/term=vendas"
  ],
  "keywords": [
    "analista de dados"
  ],
  "states": [
    "SP"
  ],
  "maxResultsPerSearch": 24
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/gupy-jobs-scraper").call(run_input={'searchUrls': ['https://portal.gupy.io/job-search/term=vendas'],
 'keywords': ['analista de dados'],
 'states': ['SP'],
 'maxResultsPerSearch': 24})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
