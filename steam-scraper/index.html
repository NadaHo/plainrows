Steam Scraper: Games, Prices & Reviews

Steam scraper and MCP tool: game details, prices, discounts, release dates, developers, genres and review scores for any list of Steam games, or their user reviews (recommended, hours played, votes, text). App IDs, store URLs or names. Pay per row + start fee.

Try it on Apify  

Typical uses

  • Price and discount tracking: the current price and discount of a list of games in any store country (US, DE, GB, BR, JP...).
  • Market research: genres, developers, publishers, release dates and review scores of a niche, for a pitch deck or a game launch.
  • Review analysis: the latest or most helpful reviews of your game or a competitor's, with hours played, for sentiment analysis or an AI summary.
  • AI agents: ask an agent "what do players complain about in game X?" and let it call this Actor through Apify's MCP server.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~steam-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "games": [
    "1145360",
    "https://store.steampowered.com/app/292030/The_Witcher_3_Wild_Hunt/",
    "Stardew Valley"
  ],
  "mode": "games",
  "maxReviewsPerGame": 20,
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/steam-scraper").call(run_input={'games': ['1145360',
           'https://store.steampowered.com/app/292030/The_Witcher_3_Wild_Hunt/',
           'Stardew Valley'],
 'mode': 'games',
 'maxReviewsPerGame': 20,
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
