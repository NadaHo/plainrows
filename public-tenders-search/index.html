Public Tenders Search: EU TED & UK Procurement API

Public tenders search and MCP tool: government contracts, notices and award winners from EU TED (Tenders Electronic Daily), UK Find a Tender and Contracts Finder: keywords, CPV, countries, value in EUR, deadlines, winners. Only-new-notices mode. Pay per notice plus a start fee per run.

Try it on Apify  

Typical uses

  • Bid opportunity alerts: every new call for tenders in your sector (CPV) and countries, still open for bids, sent daily to Sheets, Slack or your CRM. With Only new notices on, each notice is delivered and billed once.
  • Competitor and market intelligence: who wins which contracts, at what value, for which buyers; awarded values converted to EUR for comparison across countries.
  • Lead generation: award winners are companies that just got funded work (subcontracting, suppliers, financing); buyers with prior information notices are about to buy.
  • Pipeline research: prior information and market engagement notices, months before the tender.
  • AI agents and automations: a typed tool for "find tenders about X in Y" in n8n, Make, Zapier or any MCP client.

Ready-to-run examples

  • Open IT and software tenders in Europe and the UK: Find calls for tenders for software and IT services (CPV 72000000) published in the last 7 days on EU TED and UK platforms, still open for bids, with buyer, deadline and estimated value.
  • Cybersecurity contract awards over EUR 500k: See who won public cybersecurity contracts worth at least EUR 500,000 in the last 30 days across the EU and UK: winner, buyer, awarded value in EUR and date.
  • UK cleaning contract awards and winners: Find UK public contracts for cleaning services awarded in the last 30 days on Find a Tender and Contracts Finder, with supplier, buyer and value: leads and competitor intelligence.
  • Daily alert: only new public tenders for your sector: Schedule this task daily: each run returns only EU (TED) calls for tenders it has never delivered, here IT services (CPV 72) open for bids. You pay once per notice. Send them to Slack, e-mail or a sheet.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~public-tenders-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "software"
  ],
  "noticeTypes": [
    "contract-notice"
  ],
  "countries": [],
  "publishedWithinDays": 7,
  "maxResults": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/public-tenders-search").call(run_input={'keywords': ['software'],
 'noticeTypes': ['contract-notice'],
 'countries': [],
 'publishedWithinDays': 7,
 'maxResults': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
