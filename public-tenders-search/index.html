Typical uses

  • Bid opportunity alerts: every new call for tenders in your sector (CPV) and countries, still open for bids, sent daily to Sheets, Slack or your CRM. With Only new notices on, each notice is delivered and billed once.
  • Competitor and market intelligence: who wins which contracts, at what value, for which buyers; awarded values converted to EUR for comparison across countries.
  • Lead generation: award winners are companies that just got funded work (subcontracting, suppliers, financing); buyers with prior information notices are about to buy.
  • Pipeline research: prior information and market engagement notices, months before the tender.
  • AI agents and automations: a typed tool for "find tenders about X in Y" in n8n, Make, Zapier or any MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~public-tenders-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "software"
  ],
  "noticeTypes": [
    "contract-notice"
  ],
  "countries": [],
  "publishedWithinDays": 7,
  "maxResults": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/public-tenders-search").call(run_input={'keywords': ['software'],
 'noticeTypes': ['contract-notice'],
 'countries': [],
 'publishedWithinDays': 7,
 'maxResults': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
