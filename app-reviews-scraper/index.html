App Store Reviews & Google Play Reviews Scraper

App reviews scraper and MCP tool: Google Play and App Store reviews in one run: stars, title, text, date, app version and developer reply, for any app and country. No reviewer names. Only-new-reviews mode for daily alerts. An AppFollow or Appbot alternative. Pay per review plus small fees.

Try it on Apify  

Typical uses

  • Product feedback and bug triage: read what users say about the latest version, sorted newest first, with the version each review was written for.
  • Competitor research: compare your app's ratings and complaints with competitors', on both stores.
  • Review monitoring: turn on Only new reviews, schedule a daily run and alert your team in Slack or a spreadsheet: you never get (or pay for) the same review twice.
  • Sentiment analysis and AI summaries: feed clean review text to an LLM, a BI tool or an AI agent (MCP).
  • Customer support follow-up: see which reviews already have a developer reply.

Ready-to-run examples

  • Spotify reviews from Google Play and the App Store: Export the newest Spotify reviews from both stores in one run: stars, text, date, app version and developer reply, without reviewer names.
  • Get only new app reviews every day (both stores): Schedule this task daily: the first run lists the latest reviews, each later run returns only reviews it has never delivered, on Google Play and the App Store. Send them to Slack or a sheet.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~app-reviews-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "apps": [
    "com.spotify.music",
    "https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/app-reviews-scraper").call(run_input={'apps': ['com.spotify.music',
          'https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
