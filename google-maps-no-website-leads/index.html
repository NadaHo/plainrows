Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-maps-no-website-leads/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "hair salon in Odessa, TX"
  ],
  "country": "US",
  "maxPlacesPerQuery": 20,
  "website": "without"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-maps-no-website-leads").call(run_input={'searchQueries': ['hair salon in Odessa, TX'],
 'country': 'US',
 'maxPlacesPerQuery': 20,
 'website': 'without'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
