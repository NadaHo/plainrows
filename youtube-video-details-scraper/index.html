Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~youtube-video-details-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "videos": [
    "https://www.youtube.com/watch?v=jNQXAC9IVRw"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/youtube-video-details-scraper").call(run_input={'videos': ['https://www.youtube.com/watch?v=jNQXAC9IVRw']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
