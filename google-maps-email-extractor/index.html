Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-maps-email-extractor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "dentist in Austin, TX"
  ],
  "country": "US",
  "maxPlacesPerQuery": 20,
  "contactDetails": true
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-maps-email-extractor").call(run_input={'searchQueries': ['dentist in Austin, TX'],
 'country': 'US',
 'maxPlacesPerQuery': 20,
 'contactDetails': True})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
