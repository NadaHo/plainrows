Bing Search API: Bing SERP Scraper & Web Results

Bing Search API alternative and MCP tool: Bing organic web results as JSON (position, URL, domain, title, snippet) for any query, country, language, desktop or mobile. $0.0024 per query with results plus $0.0003 per result, $0.0026 per extra page of 10, $0.001 per run. Empty queries are free.

Typical uses

  • Replace the retired Bing Web Search API in scripts and apps that need Bing web results as JSON.
  • SEO on Bing: see who ranks on Bing for your keywords, by country and language, desktop or mobile.
  • Research and monitoring: collect the top Bing results for a list of topics, brands or questions on a schedule.
  • AI agents and RAG: give an LLM fresh web results (URL, title, snippet) from Bing as an MCP tool.
  • Exports: send the rows to Google Sheets, BigQuery, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~bing-search-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "crm software",
    "best project management tool"
  ],
  "country": "US",
  "device": "desktop",
  "maxResults": 10
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/bing-search-api").call(run_input={'queries': ['crm software', 'best project management tool'],
 'country': 'US',
 'device': 'desktop',
 'maxResults': 10})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
