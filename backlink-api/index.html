Backlink API: Referring Domains & Backlinks Data

Backlink API and MCP tool for AI agents: backlinks, referring domains or anchor texts of any domain or URL as JSON (anchor, dofollow, domain rank, spam score, dates). Referring domains checker for link audits. From $1.20 per 1,000 backlinks (Business; $2 on Starter) + $0.035/target.

Try it on Apify  

Typical uses

  • Competitor backlink research: see which sites link to a competitor, with which anchor, and which links pass authority (dofollow).
  • Referring domains check: list the domains that link to a site, with their backlink counts and the rank they pass, strongest first.
  • Link building prospecting and backlink gap: list the referring domains of competing sites, then keep the ones that link to competitors but not to you ([free n8n template](https://nadaho.github.io/plainrows/templates/backlink-gap-sheets.json)).
  • Backlink audits: spot spammy, broken, lost or nofollow links pointing to your site.
  • New link monitoring: sort by newest to see links found recently; schedule the run weekly.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~backlink-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "targets": [
    "backlinko.com"
  ],
  "maxResultsPerTarget": 100
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/backlink-api").call(run_input={'targets': ['backlinko.com'], 'maxResultsPerTarget': 100})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
