Get every open job from any Lever job board (jobs.lever.co): title, department, team, locations, country, remote/hybrid/onsite, employment type, salary range when published, posted date, apply link and full description. Paste the board URL or its name. Pay per job plus a small start fee.

Try it on Apify  

Typical uses

  • Job boards and aggregators: fill a niche board with fresh jobs straight from the startups and tech companies that hire through Lever.
  • Sales and recruiting intelligence: which target accounts are hiring, for which departments and teams, in which cities and countries.
  • Market and talent research: count openings per team, follow hiring trends, compare published salary ranges across companies.
  • Job seekers and career tools: watch a list of companies for new roles matching your keywords or locations. With Only new jobs on, a scheduled run returns (and bills) only jobs it has never delivered.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets, Airtable or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~lever-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "companies": [
    "https://jobs.lever.co/zoox",
    "https://jobs.lever.co/spotify",
    "palantir"
  ],
  "maxJobsPerCompany": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/lever-jobs-scraper").call(run_input={'companies': ['https://jobs.lever.co/zoox',
               'https://jobs.lever.co/spotify',
               'palantir'],
 'maxJobsPerCompany': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
