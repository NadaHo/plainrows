Greenhouse, Lever and Ashby jobs in one JSON format

You want the open jobs of a list of companies: for a niche job board, hiring signals for sales, or a job alert. Most of these companies publish their jobs through an applicant tracking system (ATS) that has a free public API. The catch is that every ATS answers in its own format.

The public job board APIs, side by side

All four endpoints below answer without a key (checked on 2026-10-09), but the same job looks different in each:

So a script that covers several ATS needs one parser per ATS, a way to find which ATS (and which board name) a company uses, and something to remember which jobs it has already seen.

One format for all of them

ATS Job Postings reads those same official endpoints (plus Recruitee and Workable) and returns one row per job in a single format: title, department, team, locations, isRemote, employmentType, salaryMin / salaryMax / salaryCurrency when the company publishes them, postedAt in UTC, applyUrl and the full description as plain text.

  • Give careers page URLs or plain company names (stripe, ramp): the ATS is detected for you.
  • Filter by title keywords, location, department, remote only or posting date for free: filtered-out jobs are not billed.
  • With Only new jobs on a daily schedule, each run returns and bills only jobs it has never delivered.

When to call the ATS APIs yourself

  • All your companies use the same ATS and you already know their board names: one parser is little work, and the API is free.
  • You need a field we do not keep, such as Greenhouse custom questions or Lever's raw lists.

When one normalized feed is simpler

  • Your list mixes Greenhouse, Lever, Ashby and others, or you only have company names.
  • You want new jobs only, from n8n, Make, Zapier, Google Sheets or an AI agent (MCP), without hosting a database of seen jobs.

Companies that publish jobs only on LinkedIn or Indeed are not in an ATS feed: Google Jobs Scraper covers those by search.
