Typical uses

  • Product and niche research: price range, ratings and sales signals ("bought in past month") for any keyword, before you launch or source a product.
  • Amazon SEO and rank tracking: where your ASIN and your competitors' ASINs rank for your keywords, organic and sponsored.
  • Price monitoring: schedule the same keywords daily and track price, coupons and badges over time.
  • Market comparison: the same keyword on amazon.com, amazon.de and amazon.co.jp in one go (one run per marketplace).
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~amazon-product-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchQueries": [
    "wireless earbuds"
  ],
  "marketplace": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/amazon-product-search").call(run_input={'searchQueries': ['wireless earbuds'], 'marketplace': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
