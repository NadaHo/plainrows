Keyword Rank Checker: Google SERP Position Tracker API

Keyword rank checker, SERP rank tracker and MCP tool: for each keyword, your Google organic position and ranking URL, competitor positions, the top 10 results and SERP features (featured snippet, local pack, People Also Ask). Pay per keyword, plus small fees per run and per extra page.

Try it on Apify  

Typical uses

  • Rank tracking: check where your site ranks on Google for 10 or 1,000 keywords, by country and language.
  • Competitor positions: add competitor domains and see, keyword by keyword, who ranks above whom.
  • SERP analysis: the top 10 results (domain, URL, title) and which SERP features Google shows, before you write content.
  • Featured snippet tracking: `featuredSnippetOwned` says whether the snippet comes from your site.
  • Weekly reports: schedule a run and send the table to Google Sheets, Looker Studio, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~keyword-rank-checker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domain": "hubspot.com",
  "keywords": [
    "crm software",
    "best crm for small business",
    "free crm"
  ],
  "competitorDomains": [
    "salesforce.com",
    "zoho.com"
  ],
  "country": "US",
  "depth": 10
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/keyword-rank-checker").call(run_input={'domain': 'hubspot.com',
 'keywords': ['crm software', 'best crm for small business', 'free crm'],
 'competitorDomains': ['salesforce.com', 'zoho.com'],
 'country': 'US',
 'depth': 10})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
