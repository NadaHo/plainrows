Trustpilot Reviews Scraper: New Reviews & Replies

Get Trustpilot reviews of any company: stars, title, text, date, language, verified flag and the company reply, plus the company's TrustScore and review count. Paste domains or Trustpilot links. No reviewer names. Only-new-reviews mode for alerts. Pay per review.

Try it on Apify  

Typical uses

  • Review monitoring and alerts: turn on Only new reviews, schedule a daily run and send new 1- and 2-star reviews to Slack, e-mail or a spreadsheet: you never get (or pay for) the same review twice.
  • Competitor benchmarking: compare TrustScores, complaints and reply habits of the companies in your market.
  • Customer-experience research: what customers praise or complain about, by star rating and language.
  • Sentiment analysis and AI summaries: feed clean review text to an LLM, a BI tool or an AI agent (MCP).
  • Agencies: weekly or monthly reputation reports for e-commerce and service clients.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~trustpilot-reviews/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "companies": [
    "www.booking.com"
  ],
  "maxReviewsPerCompany": 20,
  "sortBy": "recency"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/trustpilot-reviews").call(run_input={'companies': ['www.booking.com'],
 'maxReviewsPerCompany': 20,
 'sortBy': 'recency'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
