Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~website-traffic-checker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "backlinko.com"
  ],
  "country": "US",
  "topKeywords": 0
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/website-traffic-checker").call(run_input={'domains': ['backlinko.com'], 'country': 'US', 'topKeywords': 0})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
