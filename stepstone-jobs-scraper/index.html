StepStone jobs scraper and MCP tool: give job titles or stepstone.de search URLs, get the job offers (up to 1,000 per search): title, company, location, date posted, salary range (estimated or not), home office, snippet, labels, link. No login. Pay per job offer, plus a small start fee per run.

Typical uses

  • Job market research: how many offers for a role, in which cities, at what salary range.

  • Job alerts and aggregators: new offers for your keywords, deduplicated across searches.
  • Spreadsheets, BI and AI agents: clean rows for Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~stepstone-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "software entwickler"
  ],
  "location": "Berlin",
  "maxResultsPerSearch": 25
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/stepstone-jobs-scraper").call(run_input={'searches': ['software entwickler'],
 'location': 'Berlin',
 'maxResultsPerSearch': 25})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
