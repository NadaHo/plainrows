Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~ai-search-brand-visibility/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "prompts": [
    "best standing desk for small spaces"
  ],
  "brandNames": [
    "FlexiSpot"
  ],
  "brandDomain": "flexispot.com",
  "competitors": [
    "Uplift",
    "Desky",
    "IKEA"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/ai-search-brand-visibility").call(run_input={'prompts': ['best standing desk for small spaces'],
 'brandNames': ['FlexiSpot'],
 'brandDomain': 'flexispot.com',
 'competitors': ['Uplift', 'Desky', 'IKEA'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
