Broken Link Checker: 404s, Redirect Chains & Sitemaps

Crawl any website and find broken links (404, 500, dead domains), redirect chains and sitemap problems, with the page and anchor text of each bad link. Checks internal, external, image, script and CSS links. Fast HTTP crawler, no browser. Pay only per page crawled.

Try it on Apify  

Typical uses

  • SEO audits: broken internal links, 404s, redirect chains and noindex pages before they cost you rankings and crawl budget.
  • Site migrations and redesigns: run it after a launch to catch links still pointing to old URLs (301 chains) or to pages that no longer exist.
  • Sitemap checks: find sitemap URLs that redirect, return errors, are noindex, or are not linked from any page (orphan pages).
  • Agencies and freelancers: audit client sites in bulk (up to 100 websites per run) and feed the results to Google Sheets or a report.
  • Monitoring: schedule a weekly run and get alerted when a new broken link appears.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~broken-link-checker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "startUrls": [
    {
      "url": "https://the-internet.herokuapp.com/"
    }
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/broken-link-checker").call(run_input={'startUrls': [{'url': 'https://the-internet.herokuapp.com/'}]})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
