Bulk tech stack lookups without a $250 subscription

You want to know what a list of websites is built with, inside a spreadsheet, a CRM, n8n or an AI agent: CMS, ecommerce platform, analytics, CDN, email provider. Here is where Wappalyzer's plans stand, and what PlainRows offers.

Wappalyzer plans

From wappalyzer.com/pricing on 2026-10-08:

  • Free: 50 lookups and email verifications per month.
  • Pro: $250 per month for 5,000 lookups, API access included.
  • Business: $450 per month for 20,000 lookups and 20,000 API credits. API credits "expire after 60 days".

What PlainRows charges

No subscription to us. The tool runs on Apify: the free Apify plan is enough to test it, and the Starter plan ($19 per month, with $19 of usage included, apify.com/pricing) removes the free-plan limits.

DataToolPrice (Starter plan)
Technologies found on the homepage of each website, matched against 7,600+ open-source fingerprints, with versions when shown: one column per category (CMS, ecommerce, analytics, tag managers, advertising, CRM, email, live chat, payments, CDN, hosting, frameworks...), plus title, meta description, language, server headers, and the e-mails, phone links and social profiles shown on the homepage. When Wappalyzer is the better choice

  • You need technologies that only appear after JavaScript runs or on pages other than the homepage. PlainRows loads the homepage over HTTP, without a browser, so it can miss them.
  • You want ready-made lead lists of all sites using a technology, company details and email verification in the same tool.
  • You only check a few sites a month: the free plan's 50 lookups may be enough.

When PlainRows is the better choice

  • You already have a list of domains and want their stack in bulk, at a price per website rather than per month.
  • You want one spreadsheet-ready row per site, with one column per category, to filter on ecommerce = Shopify in one click.
  • You also want the e-mails, phone links and social profiles shown on each homepage, in the same row, at no extra cost.
  • You run it from n8n, Make, Zapier, Google Sheets or an AI agent (MCP), with a hard cap: every run stops at the maximum cost you set.
