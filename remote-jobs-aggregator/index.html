Remote Jobs Scraper & API: Himalayas, RemoteOK, Jobicy

Remote jobs scraper and MCP tool: remote jobs from the Himalayas, RemoteOK, Jobicy and Arbeitnow public APIs in one table: title, company, salary, location, tags, date, apply link. Same job on 2 sources = 1 row. Pay per job ($0.0009 or less) plus a $0.001 start fee per run.

Typical uses

  • Remote job boards and newsletters: fill your own remote job board, Slack channel or weekly newsletter with fresh jobs (`publishedWithinDays: 1`).
  • Job alerts: a daily run per keyword ("python", "product designer", "customer support") sent to Google Sheets, Notion or e-mail via n8n, Make or Zapier.
  • Recruiting and sales: which companies hire remotely, for which roles, with which salary.
  • Market research: salary ranges, seniority and countries allowed for remote roles in your field.
  • AI agents: one tool call for remote jobs across four sources, deduplicated.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~remote-jobs-aggregator/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "keywords": [
    "python"
  ],
  "maxResultsPerSource": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/remote-jobs-aggregator").call(run_input={'keywords': ['python'], 'maxResultsPerSource': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
