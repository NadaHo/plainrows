PlainRows

Every keyword a competitor ranks for, one row per keyword

You want the list of Google keywords a competitor gets traffic from, with the page that ranks for each one, in a spreadsheet you can sort and filter: to find content gaps, plan pages or brief a writer. Here is how to get it without an SEO suite.

What the usual tools give you

  • SEO suites show this report (often called "organic research" or "organic keywords") inside their interface. On 2026-10-09, Semrush's free tier allowed 10 reports per day, and its cheapest paid plan, "SEO", was listed at €112.52 per month billed annually (semrush.com/prices, viewed from Europe).
  • That is a good deal if you use the suite every day. It is a lot for a list of keywords you need once a month for a handful of competitors.

The same list as rows

Website Traffic Checker takes a list of domains and, with topKeywords set up to 1,000, returns the keywords that bring each site the most Google organic traffic: keyword, position, ranking url, estimatedTraffic, searchVolume, cpcUsd, keywordDifficulty and searchIntent, plus the site's estimated organic traffic and keyword count. 20 countries.

To get one row per keyword (CSV, Excel, Google Sheets), add unwind=topKeywords to the dataset export URL, for example https://api.apify.com/v2/datasets/DATASET_ID/items?unwind=topKeywords&format=csv. Each row then carries its domain, so several competitors fit in one sheet.

When an SEO suite is the better choice

  • You need more than 1,000 keywords per site, position history over years, or the suite's own numbers. Our data comes from DataForSEO, so values differ from Semrush or Ahrefs, as they differ between any two SEO tools.
  • You also use rank tracking, site audits and content tools every day.

When this is the better choice

  • You need the list now and then, for a few sites, and want it as rows rather than screens.
  • You run it from n8n, Make, Zapier, Google Sheets or an AI agent (MCP) on a schedule, with one Apify token.
