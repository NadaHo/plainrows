Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~kijiji-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "road bike",
    "https://www.kijiji.ca/b-cars-trucks/ontario/honda-civic/k0c174l9004"
  ],
  "maxResultsPerSearch": 40
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/kijiji-scraper").call(run_input={'searches': ['road bike',
              'https://www.kijiji.ca/b-cars-trucks/ontario/honda-civic/k0c174l9004'],
 'maxResultsPerSearch': 40})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
