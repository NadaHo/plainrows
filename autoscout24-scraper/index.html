Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~autoscout24-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searches": [
    "bmw x5",
    "https://www.autoscout24.de/lst/volkswagen/golf?sort=price&desc=0"
  ],
  "maxResultsPerSearch": 40
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/autoscout24-scraper").call(run_input={'searches': ['bmw x5',
              'https://www.autoscout24.de/lst/volkswagen/golf?sort=price&desc=0'],
 'maxResultsPerSearch': 40})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
