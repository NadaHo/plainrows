Typical uses

  • Lead generation and cold outreach: lists of tradies, clinics, shops or agencies in a city, with phone and website.

  • Market research: how many plumbers, dentists or cafes Yellow Pages lists in each city, and how they are rated.
  • CRM enrichment: match your accounts to their Yellow Pages profile, phone and categories.
  • Spreadsheets, BI and AI agents: clean rows for Google Sheets, n8n, Make, Zapier or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~yellowpages-au-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchUrls": [
    "https://www.yellowpages.com.au/sydney-nsw/plumbers"
  ],
  "categories": [
    "electricians"
  ],
  "locations": [
    "Melbourne VIC"
  ],
  "maxResultsPerSearch": 60
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/yellowpages-au-scraper").call(run_input={'searchUrls': ['https://www.yellowpages.com.au/sydney-nsw/plumbers'],
 'categories': ['electricians'],
 'locations': ['Melbourne VIC'],
 'maxResultsPerSearch': 60})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
