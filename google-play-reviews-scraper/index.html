Google Play Reviews Scraper: Ratings, Text & Replies

Scrape Google Play reviews of any Android app: stars, review text, date, app version, thumbs-up count and developer reply, in 20 countries. Paste a package name or Play Store link. No reviewer names. Only-new-reviews mode for daily alerts. Pay per review plus small fetch and start fees.

Try it on Apify  

Typical uses

  • Product feedback and bug triage: read what Android users say about the latest version, newest first, with the app version each review was written for.
  • Competitor research: compare your app's ratings and complaints with competitors' on Google Play.
  • Review monitoring: turn on Only new reviews, schedule a daily run and alert your team in Slack or a spreadsheet: you never get (or pay for) the same review twice.
  • Sentiment analysis and AI summaries: feed clean review text to an LLM, a BI tool or an AI agent (MCP).
  • Customer support follow-up: see which reviews already have a developer reply, and when it was posted.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-play-reviews-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "apps": [
    "com.spotify.music",
    "https://play.google.com/store/apps/details?id=com.duolingo"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-play-reviews-scraper").call(run_input={'apps': ['com.spotify.music',
          'https://play.google.com/store/apps/details?id=com.duolingo'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
