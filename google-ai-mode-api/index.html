Typical uses

  • AI search visibility (GEO / AEO): which sites does Google AI Mode cite for the queries your buyers type? Is yours one of them?

  • Content gaps: read what the answer says, and which competitors it cites, before writing your own page.
  • Answers with sources for your app or agent: Google AI Mode as plain JSON, with the citations kept apart from the text.
  • Weekly reports: schedule a run and send the rows to Google Sheets, Looker Studio, Slack, n8n, Make or Zapier.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-ai-mode-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "best standing desk for small spaces",
    "Which CRM do small agencies recommend in 2026?"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-ai-mode-api").call(run_input={'queries': ['best standing desk for small spaces',
             'Which CRM do small agencies recommend in 2026?'],
 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
