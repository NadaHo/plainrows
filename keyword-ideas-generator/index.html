Typical uses

  • Content plans and topic clusters: hundreds of long-tail questions and phrases around a topic, sorted by volume or by difficulty.
  • Low-competition keywords: keep ideas under a difficulty of 30 with at least 100 searches a month.
  • PPC research: CPC and top-of-page bid range for every idea, per country.
  • Product and market research: see how people search for a product category with the `ideas` source.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with clean JSON rows.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~keyword-ideas-generator/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "seedKeywords": [
    "coffee maker"
  ],
  "mode": "suggestions",
  "country": "US",
  "maxIdeasPerSeed": 100
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/keyword-ideas-generator").call(run_input={'seedKeywords': ['coffee maker'],
 'mode': 'suggestions',
 'country': 'US',
 'maxIdeasPerSeed': 100})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
