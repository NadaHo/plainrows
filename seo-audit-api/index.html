Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~seo-audit-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "urls": [
    "https://apify.com",
    "https://example.com"
  ]
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/seo-audit-api").call(run_input={'urls': ['https://apify.com', 'https://example.com']})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
