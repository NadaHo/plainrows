Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~baidu-search-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "\u7b14\u8bb0\u672c\u7535\u8111",
    "python \u6559\u7a0b"
  ],
  "device": "desktop",
  "maxResults": 10
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/baidu-search-scraper").call(run_input={'queries': ['笔记本电脑', 'python 教程'], 'device': 'desktop', 'maxResults': 10})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
