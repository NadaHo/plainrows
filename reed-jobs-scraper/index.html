Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~reed-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchUrls": [
    "https://www.reed.co.uk/jobs/nurse-jobs-in-manchester"
  ],
  "keywords": [
    "data analyst"
  ],
  "locations": [
    "London"
  ],
  "maxResultsPerSearch": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/reed-jobs-scraper").call(run_input={'searchUrls': ['https://www.reed.co.uk/jobs/nurse-jobs-in-manchester'],
 'keywords': ['data analyst'],
 'locations': ['London'],
 'maxResultsPerSearch': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
