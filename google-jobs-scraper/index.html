Get Google Jobs listings for any job search and city, gathered from LinkedIn, Indeed, ZipRecruiter and company career sites: title, company, location, salary (min/max/period), job type, posting date, job board and apply link. 20 countries. Only-new-jobs mode for daily alerts. Pay only per job.

Typical uses

  • Job market and salary research: who is hiring for a role in a city, at which pay, on which job boards.
  • Recruiting and staffing leads: companies hiring right now for the roles you place, with the link to each job.
  • Job board and newsletter feeds: fresh jobs for a niche (remote, nursing, data...) every day; turn on Only new jobs to get and pay for each job once.
  • Competitor hiring watch: search a company name to follow the roles it opens.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets or an MCP client with structured JSON.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "queries": [
    "data engineer in Austin, TX"
  ],
  "country": "US"
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-jobs-scraper").call(run_input={'queries': ['data engineer in Austin, TX'], 'country': 'US'})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
