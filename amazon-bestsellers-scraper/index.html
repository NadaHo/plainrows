Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~amazon-bestsellers-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "lists": [
    "https://www.amazon.com/gp/bestsellers/electronics/",
    "https://www.amazon.com/gp/new-releases/books/"
  ],
  "maxResultsPerList": 30
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/amazon-bestsellers-scraper").call(run_input={'lists': ['https://www.amazon.com/gp/bestsellers/electronics/',
           'https://www.amazon.com/gp/new-releases/books/'],
 'maxResultsPerList': 30})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
