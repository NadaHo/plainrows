Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~telegram-channel-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "channels": [
    "durov"
  ],
  "maxPostsPerChannel": 20
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/telegram-channel-scraper").call(run_input={'channels': ['durov'], 'maxPostsPerChannel': 20})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
