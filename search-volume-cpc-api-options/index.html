Search volume, CPC and keyword ideas by API: what each route requires

You want Google search volumes, CPC and keyword ideas in a script, a spreadsheet, n8n or an AI agent. One route is the Google Ads API, another is a commercial SEO data provider. Here is what each requires, and what PlainRows offers.

What the Google Ads API requires for keyword data

From Google's Google Ads API access levels page on 2026-10-08:

  • Every call needs a developer token. Test access works on test accounts only.
  • At Explorer access, keyword planning services (KeywordPlanService, KeywordPlanIdeaService) are restricted; to use them you need Basic or Standard access.
  • Basic access requires brand verification first, then an application reviewed in about 10 business days; 15,000 operations per day. Standard access (unlimited operations) involves a detailed manual audit.

Getting that access is a project of its own, and you still write the OAuth and request code.

When the Google Ads API is the better choice

  • You already have Basic or Standard access, or you build a product that needs Google's own figures at very large volume.
  • You need forecasts tied to your own campaigns, bids and budgets.

When PlainRows is the better choice

  • You need volumes and ideas now, for a content plan, an SEO audit or an AI agent, without an application and a review.
  • You run it from n8n, Make, Zapier or Google Sheets and pay only for keywords with data.
