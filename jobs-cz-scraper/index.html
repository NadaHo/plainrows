Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~jobs-cz-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "searchUrls": [
    "https://www.jobs.cz/prace/praha/"
  ],
  "maxResultsPerSearch": 30
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/jobs-cz-scraper").call(run_input={'searchUrls': ['https://www.jobs.cz/prace/praha/'], 'maxResultsPerSearch': 30})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
