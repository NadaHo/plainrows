Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~seo-competitors-keyword-gap/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "domains": [
    "plausible.io"
  ],
  "country": "US",
  "gapCompetitors": 1,
  "maxGapKeywords": 50
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/seo-competitors-keyword-gap").call(run_input={'domains': ['plausible.io'],
 'country': 'US',
 'gapCompetitors': 1,
 'maxGapKeywords': 50})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
