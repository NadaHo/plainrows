Typical uses

  • Content ideas and FAQ sections: the questions Google shows in "People also ask" for your topic, ready to answer in your articles and FAQ pages.
  • Long-tail keyword research: autocomplete with A to Z and question expansions (the "alphabet soup" method), as clean JSON.
  • SEO briefs: one run gives the suggestions, the questions and the related searches around a topic.
  • Local and international markets: 20 countries, with question words localized for English, German, French, Spanish, Italian, Dutch, Portuguese, Polish, Swedish and Japanese.
  • Automations and AI agents: feed n8n, Make, Zapier, Google Sheets, an LLM content pipeline or an MCP client.

Run it from your code

Get an API token in the Apify Console (Settings → Integrations), then:

curl -X POST \
  "https://api.apify.com/v2/acts/plainrows~google-autocomplete-questions/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "seedKeywords": [
    "running shoes"
  ],
  "mode": "both",
  "country": "US",
  "maxResultsPerSeed": 300
}'
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("plainrows/google-autocomplete-questions").call(run_input={'seedKeywords': ['running shoes'],
 'mode': 'both',
 'country': 'US',
 'maxResultsPerSeed': 300})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row)
